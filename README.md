## 👋 About me

I work on **computer vision and deep learning**, with a growing focus on **models that know when they are unsure**. I like to understand methods from the inside: many of my projects implement the algorithm from scratch (NumPy first, frameworks second) and then study *why* it works.

- 🔭 **Exploring:** diffusion models, evidential deep learning, uncertainty estimation for object detection
- 🧪 **Enjoy:** probabilistic models, kernel methods, generative models, segmentation and tracking
- ✍️ **Writing:** explainers on ML topics on [Medium](https://medium.com/@mefeincir)
- 📫 **Reach me:** [efeincir@hotmail.com](mailto:efeincir@hotmail.com) or on [LinkedIn](https://linkedin.com/in/ncrefe)
